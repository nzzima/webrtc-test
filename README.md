# Тест прямого канала WebRTC

Одна страница для проверки двух вещей на мобильном интернете:

1. Какие публичные STUN-серверы выдают внешний адрес.
2. Соединяются ли два телефона напрямую, без TURN.

Анкеты WebRTC передаются вручную: страница показывает анкету QR-кодом, а второй телефон сканирует
его камерой. Можно и переслать текст анкеты в любом мессенджере. Страница ничего не отправляет на сервер,
кроме запросов к STUN-серверам из списка. Открывайте в Chrome или Safari, не во встроенном браузере
мессенджера.

Страница: https://nzzima.github.io/webrtc-test/

Библиотеки для QR лежат рядом со страницей, чтобы не зависеть от CDN:
`qrcode.js` ([qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) 1.4.4, MIT) рисует код,
`jsQR.js` ([jsQR](https://github.com/cozmo/jsQR) 1.4.0, Apache-2.0) читает его с камеры.
