# Тест прямого канала WebRTC

Одна страница для проверки двух вещей на мобильном интернете:

1. Какие публичные STUN-серверы выдают внешний адрес.
2. Соединяются ли два телефона напрямую, без TURN.

Анкеты WebRTC передаются вручную через любой мессенджер. Страница ничего не отправляет на сервер,
кроме запросов к STUN-серверам из списка. Открывайте в Chrome или Safari, не во встроенном браузере
мессенджера.

Страница: https://nzzima.github.io/webrtc-test/
